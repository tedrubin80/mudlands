Command System

Intuitive commands for every action

Movement

  • north/n - Move north
  • south/s - Move south
  • east/e - Move east
  • west/w - Move west
  • up/u, down/d - Vertical movement

Interaction

  • look/l - Examine surroundings
  • examine <target> - Inspect object/NPC
  • talk <npc> - Converse with NPCs
  • attack <target> - Engage in combat

Inventory

  • inventory/i - Check items
  • get <item> - Pick up item
  • drop <item> - Drop item
  • equip <item> - Wear/wield gear

Communication

  • say <msg> - Speak in room
  • yell <msg> - Shout to nearby rooms
  • whisper <player> - Private message
  • chat <msg> - Global chat

DM Tools

  • roll <dice> - Roll dice (1d20, 3d6+2)
  • dm npc <type> - Generate NPC
  • dm quest <level> - Generate quest
  • dm monster - Generate monster

Character

  • stats/score - View character sheet
  • class - View current class
  • skills - View skill trees
  • quests - List active quests
